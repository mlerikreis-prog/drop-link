# Referência visual

A interface implementada em `frontend/public` segue a direção visual aprovada:
- sidebar escura;
- cards KPI;
- dashboard operacional;
- integração Mercado Livre;
- estoque e fornecedores;
- tabela de pedidos;
- responsividade.

A imagem de referência foi usada como direção de design, não como conteúdo funcional.
